# Phase 0 - Week 1

## Learn
Automate the Boring Stuff, Chapters 1-2 (~1 hour).
Key concepts: variables, types, `int()`/`float()`/`str()`, f-strings.

## Build (by hand - NO AI copy-paste)

### 1. age_100.py
Ask for a name and an age, then print:
`Hi <name>, you'll be 100 in <year>.`
(Calculate the year: current year + (100 - age).)

### 2. sum_two.py
Ask for two numbers, print their:
- sum
- difference
- product
- average

### 3. celsius_to_f.py
Ask for a temperature in Celsius, print it in Fahrenheit.
Formula: `F = (C * 9/5) + 32`

## Ship
Commit all three to this repo. Each should run without errors when tested.
